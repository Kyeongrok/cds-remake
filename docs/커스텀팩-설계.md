# 커스텀 팩 설계

개발도구로 고친 값을 **팩**으로 묶어 내보내고, 게임을 시작할 때 골라 쓰는 기능. 업데이트와 상관없이 돈다.
계기: 버그 리포트 #16-1 — 편집기로 인물 능력치 · 후원자 수치를 고치고 싶고, 손으로 고친 표가 업데이트 때 되돌아간다.

> 이름: 「모드」는 이미 설정 옵션(모드 창 · ModPreset) 뜻으로 쓰여 겹친다. 이 문서는 **커스텀 팩**(줄여 팩)이라 부른다. — 정할 것 1

## 1. 지금 어떻게 되어 있나 (조사 결과)

- **고친 표가 사라지는 까닭.** 표 자리(`TableCache.Folder`)는 설치판에서 `%LOCALAPPDATA%\CdsHelper\current\exe-tables` 다. Velopack 업데이트가 `current` 를 통째로 바꾼다.
  대본 책만 `disev-kept` 로 지키고, 나머지 `*-edits.json` · `persons-edits.json` 등은 지키는 장치가 없다.
  (여러 주석의 「`%APPDATA%\CdsHelper\exe-tables` 에 남는다」는 옛 동작이고 지금은 안 맞는다.)
- **개발도구가 고치는 것.** 국가 · 문화권 · 인물(기술 · 언어 등, 능력치 · 계약금 칸은 없음) · 선수상 · 소문 · 패시브 · 경쟁자 · 도시/왕국 · 대본(이벤트) · 부대 편성 · 운명 자리 · 힌트 · 책 · 발견물 · 묘책 확률 · 시나리오.
  모두 `exe-tables/*-edits.json` 같은 표 파일에 쓴다. **후원자 창은 보기만** 한다.
- **업데이트에 안 지워지는 자리**는 `%APPDATA%\CdsHelper`(세이브 · 설정 · 등록 배 `ships\` · 사용자 발견물 `discoveries\` · 애드온).
- **표는 세이브로 복사되지 않는다.** 켤 때 · 필요할 때 읽는다(인물표는 부를 때마다, 후원자 · `*-edits` 는 한 번 읽어 캐시).
  예외: 고용한 부하의 능력치 · 기술(`MateBook`), 주인공 값, 후원자 친밀도 · 지갑, 배 능력치는 세이브에 들어간다.
- **선례.** 시나리오 · 발견물은 이미 zip 내보내기/들이기가 있고(`ScenarioPackage` · `DiscoveryPackage` · `UserDiscoveries`), 세계지도는 층 읽기(저장소 → `%APPDATA%` → 실행 폴더)를 한다.

## 2. 설계

### 2.1 팩 폴더
```
%APPDATA%\CdsHelper\packs\<팩 이름>\
    pack.json            이름 · 만든 이 · 설명 · 만든 게임 판 · 형식 판(1)
    persons-edits.json   표 파일과 같은 ASCII 이름 — 들어 있는 것만 덮어 얹는다
    sponsors-edits.json
    nations-edits.json …
```
- 업데이트가 건드리지 않는 `%APPDATA%` 밑이다.
- **한 번에 한 팩만** 켠다(겹쳐 쓰기는 나중에). — 정할 것 4

### 2.2 읽기 — 층 하나 더
`TableCache.Read(이름)` 가 **켠 팩 폴더 → 기본 표 자리** 차례로 찾는다. 이것 하나로 지금 `*-edits` 를 쓰는 모든 표가 팩을 따른다.

- 팩 파일은 **고친 줄만**(id 열쇠로) 담는다. 지금 `persons-edits.json` 처럼 표 전체를 쓰면, 업데이트로 기본 표가 바뀔 때 팩이 옛 값으로 전부 덮는다.
  고친 줄만 담으면 업데이트로 고쳐진 다른 줄은 그대로 받는다. — 정할 것 5
- 표 형식(Version)이 바뀌어 팩 파일을 못 읽으면 그 표만 건너뛰고 알린다(게임은 기본 값으로 돈다).

### 2.3 쓰기 — 개발도구
- 개발도구 위쪽에 「지금 팩: 없음 ▾」 고르개를 둔다. 팩을 골라 두면 모든 편집 창이 **그 팩 폴더에** 쓴다. 「없음」이면 지금처럼 기본 표 자리에 쓴다(개발용).
- 팩 만들기 · 이름 바꾸기 · 지우기 · **내보내기(zip)** · **들이기(zip)**. zip 안은 팩 폴더 그대로 + `pack.json`.
- 첫 단계에 새로 여는 편집 칸:
  - 인물 창에 **능력치 6칸**(체력 · 지력 · 무력 · 매력 · 운 · 신앙)과 계약금.
  - 후원자 창을 **고칠 수 있게** — 안목 · 인심 · 취향 · 재력 · 언어 · 자리 · 등장/은퇴 연도. `sponsors-edits.json` 에 쓴다.

### 2.4 게임 — 팩 고르기
- 타이틀(시작 화면)에 「커스텀 팩: 없음 ▾」. 고르면 표 캐시를 비우고 다시 읽는다. **판을 시작하기 전에만** 바꾼다(게임 중 바꾸면 이미 읽은 값과 섞인다). — 정할 것 3
- 세이브에 「시작한 팩 이름 · 지문」을 적는다. 다른 팩(또는 없음)으로 그 세이브를 불러오면 「이 세이브는 ○○ 팩으로 시작했습니다」를 묻는다.
- 팩을 켠 판은 하드코어 랭킹에 「팩 사용」으로 표시하거나 랭킹에서 뺀다. — 정할 것 6
- 업데이트 뒤에도 팩 고르기는 `game-settings.json` 에 남는다.

### 2.5 조심할 것
- 부하 · 후원자 친밀도는 세이브가 **이름**으로 찾는다. 팩이 인물 · 후원자 이름을 바꾸면 기존 세이브에서 이어지지 않는다 → 이름 칸은 팩에서 못 바꾸게 하거나 경고. — 정할 것 7
- 이미 고용한 부하는 고용 때 베낀 능력치를 쓰므로, 팩을 바꿔도 그 부하 값은 안 바뀐다(새로 고용하는 사람부터).
- 등록 배(`ships\`)와 사용자 발견물(`discoveries\`)은 이미 업데이트에 안전하다. 첫 단계에서는 팩에 넣지 않고 그대로 둔다(나중에 팩 zip 에 함께 담기).

## 3. 단계
1. 층 읽기(`TableCache`) + 팩 폴더 + 개발도구 고르개 · 쓰기 + 게임 타이틀 고르개 + 세이브 표시. 인물 능력치 · 후원자 편집 칸.
2. 내보내기 · 들이기(zip) — 시나리오 · 발견물 꾸러미 틀 재사용.
3. (나중) 등록 배 · 사용자 발견물 · 대본을 팩에 함께 담기, 여러 팩 겹쳐 쓰기.

## 4. 정한 것 (2026-11-07, 모두 권장대로)
이름 「커스텀 팩」 · 1단계 범위 위와 같이 · 타이틀에서만 고름 · 한 번에 한 팩 · 고친 줄만 담기 · 하드코어 랭킹 제외 · 이름은 팩에서 못 바꿈.

### 처음 물은 것
1. **이름** — 「커스텀 팩」? 「사용자 모드」? 「나만의 모드」?
2. **첫 단계 범위** — 위 1단계(인물 능력치 · 후원자 + 모든 `*-edits` 표 자동 포함)면 될지.
3. **고르는 자리** — 타이틀에서만(권장) / 모드 창에도.
4. **한 번에 한 팩**(권장) / 여러 팩 겹치기.
5. **고친 줄만 담기**(권장 — 업데이트로 고쳐진 다른 값은 받음) / 표 통째.
6. **하드코어** — 팩 켠 판은 랭킹 제외(권장) / 표시만.
7. **이름 바꾸기** — 팩에서 인물 · 후원자 이름은 못 바꾸게(권장) / 경고만.
