# 펼친 책 그림

도서관에서 책을 읽으면 뜨는 펼친 책이다. 파일 이름은 **그림 번호**다(`B{번호}.png`).
`B0` ~ `B32` 는 원본 `OPENBOOK.CDS` 의 서른석 장을 뽑은 것이다 — 게임은 `OPENBOOK.CDS` 를 안 읽고 이 폴더만 읽는다.

| 번호 | 크기 | 쓰임 |
|---|---|---|
| 0 | 544x304 | 펼친 책 틀(붉은 가죽) |
| 1 ~ 10 | 256x288 | 낱장 — 흰 종이 벌(2 · 3 · 4 · 9)과 누런 종이 벌(6 · 7 · 8 · 10) |
| 11 · 12 | 16x16 | 모서리 단추(다음장 · 앞장) |
| 13 ~ 32 | 160x240 또는 240x160 | 삽화 스무 장 — 힌트의 삽화 번호 0 ~ 19 |

## 삽화 더하기

새 삽화는 `B33.png`(삽화 번호 20)부터 넣는다. 크기는 160x240(선 것) 아니면 240x160(누운 것)이다.
원본 낱장 번호는 크기를 코드의 표(`OpenBookArt.Sizes`)로 대 보므로 크기를 바꾸면 안 뜬다.
