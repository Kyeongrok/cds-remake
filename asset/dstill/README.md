# 발견물 그림

발견물을 찾았을 때 뜨는 그림이다. 한 장이 320x240 이고 파일 이름은 **그림 번호**다(`D{번호}.png`) —
발견물 번호가 아니다. 어느 발견물이 몇 번을 쓰는지는 발견물 표의 그림 칸(`Picture`)이 낸다.

- `D0` ~ `D83` — 원본 `DSTILL.CDS` 의 여든넉 장을 뽑은 것이다. 게임은 `DSTILL.CDS` 를 안 읽고 이 폴더만 읽는다.
- `D84` 부터 — 원본에 없던, 더해 넣은 발견물의 그림이다. 도구 앱의 발견물 그림 뷰어 「그림 더하기」가
  사진을 발견물 그림처럼 바꿔(`DiscoveryStillFilter`) 다음 번호로 넣는다.
