# 도시마다 갈아 끼우는 건물 사진

건물에 들어가면 오른쪽 아래에 뜨는 타원 사진은 원본이 `(문화권, 건물 코드)`로 `MPCG.CDS` 에서 고른다.
같은 문화권이면 도시가 달라도 같은 사진이다 — 한양은 문화권이 중국이라 북경 왕궁 사진이 떴다.

이 폴더에 `city-{도시 번호 3자리}-{건물 코드 2자리}.png`(320x240)를 두면 그 도시 그 건물만 이 그림을 쓴다
(`BuildingPhoto.TryGetCityBgra`). 타원은 원본 마스크로 자르므로 그림은 네모 그대로 둔다.
