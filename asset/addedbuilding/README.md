# 덧붙인 건물 그림

원본 도시 그림에 없는 건물을 세울 때 그림 위에 얹는 96x80 그림이다(알파로 비친다).
어느 도시 어느 자리에 얹는지는 `CityBuildingTable.Added` 가 정한다.

| 파일 | 쓰는 곳 | 출처 |
|---|---|---|
| china-market.png | 한양(190) 운종가 시전(시장, 코드 7) | 원본 도시 그림의 북경(188) · 제남(186) 시장 상자에서 두 도시의 색이 가까운 점(RGB 거리 30 안)만 남기고, 가장 큰 덩어리의 볼록 껍질로 오려 냈다. 중국 문화권 시장은 두 도시가 같은 그림이다. |
